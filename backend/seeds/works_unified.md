## 1. Oton-Zzz (oton-zzz)
- **GitHub**: https://github.com/jphacks/os_2512
- **技術スタック**: Python (OpenCV, MediaPipe), C++/Arduino (M5StickCPlus2), IRremoteESP8266, pyserial
- **開発時期**: 2025年9月〜10月
- **体制**: 5名チーム
- **受賞**: サイバーエージェント賞 (JPHACKS / 技育博)
- **ショート概要**: 家族の「テレビつけっぱなし問題」を解決する、ウェアラブル不要のAI睡眠検知IoTシステム。
- **背景・課題**: 父親がテレビをつけたまま寝てしまうことによる無駄な電気代と、家族のストレスを解決するため。現代社会において不要な電気は家計・環境の負担となり、特にテレビの消し忘れは多くの家庭に見られる問題です。

- **担当・工夫した点**: プロジェクト全体の取りまとめ（PL）、M5Stickの赤外線・シリアル通信処理、プロモーション動画制作・出演を担当。仕様書を作成してインターフェース定義を徹底し、未経験のハードウェア領域でも円滑にチーム開発を進められるよう全体像図の作成などを行いました。
- **備考**: 当初はラズパイ等を用いる案もありましたが、予算と部室にあった在庫を活用し、M5Stick+赤外線モジュールという構成に着地させました。

- **GitHub**: (未記載・個人演習)
- **技術スタック**: Python (MediaPipe, OpenCV)
- **開発時期**: 2025年8月
- **体制**: 個人（学内授業コンテスト9位）
- **ショート概要**: 手の動きだけで画面に線を描き、色を変えられるVRライクなジェスチャーアプリ。
- **背景・課題**: 特殊なデバイスなしでVRのような直感的な操作感を再現したい。
- **解決策**: カメラ映像から手の骨格を検知。「指をつまむ」で色変更、「パー」で消去するなどのジェスチャー認識を実装。
- **担当・工夫した点**: ジェスチャーの判定閾値の微調整（手が閉じているか、つまんでいるか等）に注力し、実用的な認識精度を実現。
- **備考**: Webカメラのみで本格的なAR/VR的な操作体験を構築しました。

## 20. メディアパイプを用いた姿勢推定コントローラー
- **GitHub**: (未記載・実験的プロダクト)
- **技術スタック**: Python (MediaPipe)
- **開発時期**: 2025年頃
- **体制**: 個人開発
- **ショート概要**: 姿勢推定を用いて自分の体の動きで2Dマリオ等を操作する、体感型インターフェース実験アプリ。
- **背景・課題**: 従来のコントローラーに縛られない直感的なゲームプレイの実験。骨格検知をキーボード入力信号へ変換。
- **解決策**: 特定の身体動作（ジャンプ、腕の振り等）をリアルタイムで検知し、ゲーム入力へマッピング。
- **担当・工夫した点**: 低遅延での動作検知と、誤操作を防ぐためのモーションフィルタリングの工夫。
- **備考**: MediaPipeを用いたリアルタイム姿勢推定の応用可能性を探求したプロジェクトです。
