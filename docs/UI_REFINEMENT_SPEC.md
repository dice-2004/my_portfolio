# Phase 5: UI/UX 刷新およびインタラクティブ演出の強化仕様書

## 1. 概要
本フェーズでは、3D/ARといった外部デバイス依存の機能を廃止し、ウェブブラウザ特有の表現力を最大限に引き出すことで、ポートフォリオのUI/UXを劇的に向上させます。

## 2. デザインコンセプト: "Cyber Glass & Aurora"
- **質感**: すりガラス（Glassmorphism）の透明感と鋭いエッジを強調。
- **背景**: 固定の背景ではなく、静かに色が変化し続ける「オーロラグラデーション」。
- **動作**: ユーザーの視線（スクロールやホバー）を誘導する、滑らかで心地よいアニメーション。

## 3. 実装タスク

### 3.1 背景演出 (Aurora Background)
- CSS の `background-image` と `animate` プロパティを組み合わせ、複数の色調（紫、青、ピンク）がゆったりと混ざり合う背景を実装。
- ノイズテクスチャを重ね、デジタルな高級感を演出。

### 3.2 ヒーローセクションの再定義
- タイポグラフィの強化（グラデーションテキスト、テキストシャドウ）。
- キャッチコピーが文字ごとに一文字ずつ出現するアニメーションの実装。

### 3.3 インタラクティブ・フィードバック (Framer Motion)
- **Entrance Animation**: ページ遷移時にセクション全体が下から浮き上がるような演出。
- **Card Hover**: Works のカードをホバーした際、境界線が少し発光し、わずかに傾く（3Dトルト）演出。
- **Button Micro-interactions**: クリック時やホバー時のサイズ変化、色調変化の徹底。

### 3.4 タイポグラフィの最適化
- システムフォントではなく、Google Fonts（Outfit, Inter）などを検討。
- カーニング、行間の調整による「プレミアム感」の追求。

## 4. 目標とするユーザー体験
1. **第一印象 (WOW効果)**: ページを開いた瞬間に、色の美しさと滑らかな動きで引き込む。
2. **情報の読み取りやすさ**: 装飾が過剰にならず、自己紹介や実績の内容がすっと頭に入るレイアウト。
3. **触れる楽しさ**: リンクやボタンに触れるたびに、洗練されたフィードバックがある。

## 5. 技術選定
- **Framer Motion**: アニメーションのコア。
- **Tailwind CSS**: ユーティリティクラスによるデザイン調整。
- **Lucide React**: 統一感のあるアイコンセット。
